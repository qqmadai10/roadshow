# 路演小广告生成器

打开 `index.html` 即可编辑产品、场次、基金经理与业绩资料，实时预览橙白色系海报，复制纯文字文案或下载 PNG。预设示例为永赢稳健增强债券型证券投资基金 A（014088）。

## 使用与核验

- 预设示例路演时间为 2026 年 10 月 8 日 15:00；更换场次前请填写实际日期和时间。
- 修改资料后，文案复制和海报下载会暂停，直到勾选人工核验。该网页**不会自动从基金公司或行情网站抓取、核验新数据**。
- 更换基金公司或基金经理姓名后，预设 Logo 或经理照片不会继续冒用；请上传对应官方素材。上传的图片只保留在当前浏览器会话中，刷新页面后需重新上传并核验。
- 编辑内容保存在当前浏览器本地，不会提交到服务器。请勿把未核验数据用于对外宣传。

## 永赢示例来源

- [基金产品资料概要（2026-05-30）](https://pdf.dfcfw.com/pdf/H2_AN202605301823072137_1.pdf)：产品、A 份额代码、经理、投资范围。
- [基金 2026 年第一季度报告](https://pdf.dfcfw.com/pdf/H2_AN202604221821399422_1.pdf)：经理履历，截至 2026-03-31。
- [永赢基金微讯产品介绍（新浪财经转载，2025-04-02）](https://finance.sina.com.cn/money/fund/jjzl/2025-04-02/doc-inerutki9267912.shtml)：历史策略说明与经理照片。
- [天天基金历史净值](https://fundf10.eastmoney.com/jjjz_014088.html)：同一 A 份额的累计净值；示例计算实际端点为 2026-01-05 至 2026-09-30。展示区间为 2026-01-01 至 2026-10-01。年化折算仅是数学换算；同类排名待补充。
- [永赢基金品牌 Logo 来源](https://campus.51job.com/maxwealthfund2022/)：透明背景图用于示例展示。

过往业绩不预示未来表现，基金有风险，投资需谨慎。本工具输出仅供路演信息交流，不构成投资建议或收益承诺。

## GitHub Pages 发布

将本目录所有文件放在公开仓库根目录（包括 `assets/`），在仓库 `Settings > Pages` 中选择 `Deploy from a branch`、`main`、`/(root)`。发布完成后，访问 `https://qqmadai10.github.io/roadshow/`。首次发布通常需要稍等片刻，以 GitHub Pages 设置页显示的地址为准。
